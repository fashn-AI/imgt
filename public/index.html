02 / INTEGRATION

Use with Next.js.

Your usual next/image component.
Your own image infrastructure.

Next.js handles responsive sizes and lazy loading. imgt serves the WebP. Add these three files to your app, then restart its development server.

  1. 01

    Configure the loader.

    Connect Next.js to your optimizer. Keep widths and qualities aligned with imgt.

    next.config.ts 
    import type { NextConfig } from "next";

const nextConfig: NextConfig = {
  images: {
    loader: "custom",
    loaderFile: "./image-loader.ts",
    qualities: [60, 75, 77, 85],
  },
};

export default nextConfig;
  2. 02

    Point it at imgt.

    This example uses the deployment you’re viewing. Replace the origin with your own imgt URL when you self-host.

    image-loader.ts 
    "use client";

import type { ImageLoaderProps } from "next/image";

export default function imageLoader({
  src,
  width,
  quality = 77,
}: ImageLoaderProps) {
  const url = new URL("/image", "https://imgt.YOUR-SUBDOMAIN.workers.dev");
  url.search = new URLSearchParams({
    url: src,
    w: String(width),
    q: String(quality),
  }).toString();
  return url.href;
}
  3. 03

    Use your Image.

    Set dimensions and sizes to match your layout. Next.js generates the responsive URLs.

    app/page.tsx 
    import Image from "next/image";

export default function Page() {
  return (
    <main style={{ maxWidth: 800, margin: "0 auto" }}>
      <Image
        src="https://images.unsplash.com/photo-1500530855697-b586d89ba3ee?fm=jpg&fit=crop&w=1920&h=1200&q=90"
        alt="Landscape from Unsplash"
        width={1920}
        height={1200}
        quality={77}
        sizes="(max-width: 768px) 100vw, 800px"
        style={{ width: "100%", height: "auto" }}
      />
    </main>
  );
}

SOURCE HOSTS

Use a public, absolute HTTPS image URL. Its hostname must be in your deployment’s ALLOWED_HOSTS. This example uses images.unsplash.com.
