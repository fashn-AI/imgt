03 / CHOOSE

Which one fits you?

imgt is a good fit if

  • Most images are viewed many times, or arrive steadily.
  • Image costs are a noticeable part of your bill.
  • You want to self-host on Cloudflare and use it from any app, not only Next.js.
  • You want open-source code you can read and change.

Vercel is a good fit if

  • Pages often show dozens of images nobody has requested yet.
  • Your app already runs on Vercel and setup time matters most.
  • You would rather not run any image infrastructure.

Need faster bursts with imgt? Larger or more containers help, at a higher cost. Four always-on 1-CPU containers served 200 new images in 6.8 s p95. See the container sizing guide.

How we tested

Images. Each request asked for 640 px wide WebP at quality 98, with a unique URL so nothing came from cache. Every response was decoded and checked for the right format and width. Failed requests are counted, never shown as fast.

imgt. The default setup, measured on the production deployment on November 5, 2026, alongside real traffic: an always-on 1-CPU container plus a 3-CPU overflow container that starts when four images are waiting. The overflow had been idle before each test, so its cold start is included. Sources were 50 public FASHN website images, mostly WebP.

Vercel. Measured on October 6, 2026 with 50 FASHN PNG originals. That image set has since expired, so the two services were not tested on the same files or on the same day. Treat small differences as noise.

Workloads. FASHN's busiest observed 15 minutes averaged about 2.9 new images per second. Tests at 10 and 20 per second add headroom. The 50 and 200 image tests send every request at once, like a page full of new images.

Cost. 2.25M new images and 10M total requests a month, 120 KiB per output, 0.14 CPU seconds per image and 30 days of stored results, which needs a 30-day R2 lifecycle rule. The overflow is billed for the 18% of the month it was awake in production. Vercel uses iad1 on-demand rates. Source transfer, logs, taxes and support time are excluded. These are estimates, not invoices.
